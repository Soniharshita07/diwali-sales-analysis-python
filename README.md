🪔 Diwali Sales Analysis using Python
📌 Project Overview

This project analyzes Diwali Sales Data to uncover customer purchasing behavior, identify high-value customer segments, and generate business insights that can help improve marketing and sales strategies.

The analysis focuses on answering questions like:

Who are the most valuable customers?
Which states generate the highest sales?
Which age groups buy the most?
Which product categories perform best?

This project demonstrates my practical skills as an aspiring Data Analyst in:

Data Cleaning
Exploratory Data Analysis (EDA)
Data Visualization
Business Insight Generation
🎯 Business Problem

Retail businesses need to understand customer behavior during festive seasons like Diwali to:

improve targeted marketing,
optimize inventory,
and maximize revenue.

This analysis helps identify who buys what, where, and why.

✅ Married women aged 26–35 are the most valuable customer segment.

✅ Female customers show higher purchasing power than male customers.

✅ Major revenue comes from UP, Maharashtra, and Karnataka.
